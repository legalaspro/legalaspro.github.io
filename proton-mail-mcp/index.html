Your Proton Mail, for your AI agent. Locally.

An open-source MCP server that lets agents read, search and draft mail through Proton Bridge. It runs on your machine, and nothing is hosted. 

uvx mcp-proton-mail setup --client claude-desktop

Needs a paid Proton plan (Bridge requires one), uv, and Linux or macOS. Windows support is new: read docs/windows.md first. Run it in your own terminal: it prints its plan and changes nothing until you approve. Using another client? Pick it below.

How it keeps your mail safe

Reading your mail changes nothing. Every change waits until you approve a preview. Sending is off until you turn it on.

  • Reading changes nothing. Search and read open mailboxes read-only and never mark mail as read.
  • Changes take two steps. First a preview shows the count, samples and target, and returns a single-use, short-lived token bound to exactly those messages. The server checks them again before acting and refuses if anything differs. Then your client shows a form with the exact change, and declining retires the token. Moves, labels and read state can be undone once with undo_action.
  • Sending is off by default. When you turn it on, the only path is create_draft → preview_send → send_draft. Any edit after the preview refuses.
  • You approve each send in the client’s form, or by typing OK in chat when the client has no form. The server cannot prove that a human typed the OK: only the assistant reports it. PROTON_MCP_SEND_TYPED_OK=0 turns that path off.
  • A form is only as good as the client. A client that answers forms by itself defeats this check.
  • Every write is logged in an append-only audit log, with no message bodies, subjects, full addresses or tokens.
  • There is no tool to empty Trash, or to delete or rename a mailbox. Permanent deletion reaches only drafts you approved.
  • It runs on your computer, under the same login as Bridge, and listens only on 127.0.0.1. Nothing is hosted.

Set up your client

Claude Desktop

uvx mcp-proton-mail setup --client claude-desktop

Adds a proton-mail entry to claude_desktop_config.json (on macOS in ~/Library/Application Support/Claude/). It starts proton-mail-mcp connect, which reads the token itself, so the file holds no token. Then quit Claude Desktop completely and open it again.

Claude Desktop guide

Claude Code

uvx mcp-proton-mail setup --client claude-code

Adds a user-scope proton-mail entry to ~/.claude.json, through claude mcp add when claude is on your PATH. The file holds no token. Then start a new Claude Code session.

Claude Code guide

Cursor

uvx mcp-proton-mail setup --client cursor

Adds a proton-mail entry to ~/.cursor/mcp.json. The file holds no token. Then restart Cursor, or turn proton-mail off and on under Cursor Settings › MCP.

Cursor guide

Codex

uvx mcp-proton-mail setup --client codex

Adds a [mcp_servers.proton-mail] table to ~/.codex/config.toml, through codex mcp add when codex is on your PATH. The file holds no token. Codex waits 60 seconds for a tool by default, so add tool_timeout_sec = 150 to that table by hand, then start a new Codex session.

Codex guide

Gemini CLI

uvx mcp-proton-mail setup --client gemini

Adds a user-scope proton-mail entry to ~/.gemini/settings.json, through gemini mcp add when gemini is on your PATH. The file holds no token. Then start a new Gemini CLI session; /mcp should list proton-mail.

Gemini CLI guide

ChatGPT Mac app

uvx mcp-proton-mail setup --client chatgpt

Adds a [mcp_servers.proton-mail] table to ~/.codex/config.toml, which it shares with Codex. ChatGPT connects over HTTP, so this entry holds the bearer token, and the file is written owner-only. Add tool_timeout_sec = 150 to that table by hand, then quit the ChatGPT app completely and open it again. ChatGPT on the web cannot reach your computer.

ChatGPT guide

Then ask: “How many unread messages are in my inbox?” Your agent should call count_mail, which reads and changes nothing.

Already ran setup? uvx mcp-proton-mail configure-client --client <name> adds another client, keeping the old file as a dated backup. Add --print-config to print the entry and change nothing.

Tools

The server has 30 tools by default, and 33 with sending on.

Read

Changes nothing and marks nothing read.

search_mail
Search one folder, newest first.
count_mail
Count the messages that match a search.
read_thread
Read a message or its whole thread as text.
show_thread
Show a thread in a read-only view.
list_attachments
List a message’s attachments. Downloads nothing.
read_attachment
Read one attachment: text from a PDF, TXT or CSV, or an image.
list_from_addresses
List the From addresses a draft can use.
list_rules
List your folder rules in the order they run (beta).
list_actions
Look up logged changes and audited write calls.
reindex_status
Show the progress of a search-index rebuild.

Draft

Saves new items, never sends, and is always logged.

create_draft
Save a new, unsent draft in Drafts.
compose_reply
Open a composer for a reply or a new draft. It saves only unsent drafts.
forward_message
Save an unsent draft that forwards one message, with only the attachments you choose.
save_attachment
Save one attachment as a new file in the one folder you allow.

Change, with your approval

Preview first, then a single-use token and your client’s form.

preview_action
Preview a move, archive, trash, read state, label, draft deletion or unsubscribe. Changes nothing.
move
Move, archive or trash the approved messages.
set_read_state
Mark the approved messages read or unread.
label
Add or remove a label on the approved messages.
delete_draft
Permanently delete the approved drafts. Cannot be undone.
unsubscribe
Unsubscribe from the approved senders. Cannot be undone.
preview_rulesapply_rules
Preview, then run your folder rules (beta).
preview_create_foldercreate_folder
Preview, then create a folder.
preview_add_ruleadd_rule
Preview, then save a folder rule (beta).
preview_sieve_filtercreate_sieve_filter
Preview a Sieve filter. Creating one always refuses, because Bridge cannot apply it.
reindex
Preview, start or cancel a rebuild of the local search index. Mail never changes, so there is no form.
undo_action
Reverse one logged change, once, when you ask. Needs no token or form, and is logged.

Send, off by default

These exist only with PROTON_MCP_ENABLE_SEND=1.

preview_send
Preview one saved draft and get its single-use send token.
review_send
Show that preview in a view, without a token.
send_draft
Send one previewed draft, once, after your form or typed OK. Cannot be undone.

Questions

Is it official?

No. mcp-proton-mail is unofficial and is not affiliated with or endorsed by Proton AG. It is an open-source project under the Apache-2.0 license.

Does my mail leave my computer?

The server and Bridge run on your computer, and the server listens only on 127.0.0.1. Nothing is hosted. Bridge talks to Proton as it always does.

What your agent reads becomes part of its conversation, so it goes wherever your agent’s model runs. The local search index holds headers, not message bodies, and the audit log holds no bodies.

Can the agent send without me?

Sending is off by default, and then there is no send tool at all. When you turn it on, each send needs a saved draft, a fresh preview and your approval in the client’s form.

On a client with no form, you type OK in chat instead. The server cannot prove that a human typed it, so a misled assistant could send without asking. Set PROTON_MCP_SEND_TYPED_OK=0 to turn that path off.

Sending mail has every case, including the opt-in for notes to your own addresses.

Which clients does it work with?

Setup writes the config for Claude Desktop, Claude Code, the ChatGPT Mac app, Codex, Cursor and Gemini CLI, and shows the entry for Grok Bot or another agent to add. Any other client on the same computer can connect over HTTP at http://127.0.0.1:8765/mcp. A client that runs in someone else’s cloud cannot reach it.

Do I need a paid Proton plan?

Yes. The server reads your mail through Proton Mail Bridge, and Bridge requires a paid Proton plan.

Does it run on Windows?

Native Windows support is new. It has run on GitHub’s Windows Server runners only, not on Windows 10 or 11 or with a real Proton account. Read docs/windows.md first, or use WSL2 and the Linux steps.

How do I undo a change, or uninstall?

Ask your agent to undo it: undo_action reverses a logged move, archive, trash, read-state, label or folder-rule change, once. Sending, draft deletion and unsubscribe cannot be undone.

To uninstall, see the plan first, then run it:

uvx mcp-proton-mail uninstall --dry-run
uvx mcp-proton-mail uninstall

It stops and removes the services and settings. It keeps your stored credentials unless you add --remove-credentials, Bridge unless you add --remove-bridge, and the proton-mail entry in each client’s config, which you remove yourself. Uninstall details
